# 公开版本说明

本网站帮助读者做好推特运营、获得有价值的关注。内容包括起号定位、选题与写作、互动分发和数据复盘；不承诺粉丝数量、收益或搜索零遗漏。

首页直接展示可搜索和筛选的文章卡片；文章预览区分作者原文开头和 AI 总结。正式文章仅收录最近一年内、来源可核对的中文 Article。数字为收录快照，不是实时排名。

涉及互动、自动化或奖励的经验须结合当前平台规则阅读。规则核验记录保存在源数据中，后续规则可能调整。文章的自报成绩与因果说法不等于独立验证。

当前构建只包含网站运行文件、当前展示数据、独立文章页和必要内容/许可说明。当前展示文章的封面和头像随站点分发；研究候选、历史版本文档和采集缓存不随站点分发。

## 在线文库与部署

在线入口：[guanmo-ai.github.io/awesome-x-growth](https://guanmo-ai.github.io/awesome-x-growth/)。主分支通过检查后，由 GitHub Actions 仅发布 `dist/` 到 GitHub Pages；PR 只运行检查。

当前工作流使用 `SITE_URL=https://guanmo-ai.github.io/awesome-x-growth/`。如迁移站点，需同步更新工作流、README 和仓库 Website 地址。

用已确定的正式 HTTPS 根地址构建：`SITE_URL=https://你的正式域名/ npm run build`。部署在子目录时，根地址须包含完整子目录。构建会写入绝对分享地址、canonical、sitemap 和 robots。

未设置正式地址时，仍可本地预览，但不能宣称平台分享卡片、域名、TLS 或搜索收录已经通过。请只部署生成的 dist 目录；发布后在真实域名检查首页、工具页、文章直链、分享图片与平台抓取结果。


## 公开输出与原图审阅

`npm run build` 始终输出公开候选到 `dist/`。每篇展示文章的封面和头像都进入产物，缺图则构建失败，不使用生成的替代封面。`npm run build:preview` 仅供维护者在本机审阅已有原图，输出 `.local/preview/`，不覆盖公开候选；该模式拒绝正式域名配置。

开源前运行 `npm test`、`npm run check`、`npm run build`、`npm run check:release` 与 `npm run check:repo`。发行检查拒绝本地审阅模式，仓库检查还会检查引用图片是否齐全，并拒绝未引用图片与私人材料。不要发布 `.local/preview/` 或整个工作目录。

隐藏文章时，独立页、前端 JSON 及其专用图片一同退出公开输出；同一图片若仍被其他展示文章合法引用则保留。公开图片的字段完整性不等于授权真实性，维护者仍须核对证据。
