# 当前设计约定

2026-10-16 更新。网站主线是推特运营与涨粉，内容优先回答读者正在遇到的问题。

首页先提供起号、内容、互动复盘三个入口，每项两篇阅读推荐与一个本站建议，再进入可搜索的文章库。推荐理由与建议不混入作者原文或AI总结。

暖纸色、砖红色与紫灰辅助色；不使用绿色装饰。卡片上方以本站文字提要说明阅读重点，下方保留原标题、作者、日期和互动快照。未经确认公开使用依据的第三方图片不随站点分发。

桌面四列，窄屏单列；主题按钮在窄屏全部换行显示。阅读弹窗按当前筛选顺序切换，关闭恢复焦点；文章另生成不依赖 JavaScript 的静态页面，支持新标签页和单篇分享。

工具为次级页面，优先呈现用途与边界。页面保持原生 HTML/CSS/ES modules，不引入额外运行依赖。减少动效偏好沿用既有处理。
