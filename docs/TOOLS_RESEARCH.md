# X 插件与工具研究

核验日：2026-10-12。目标有两个：帮助观默找素材、写作和运营；从现成产品中学习如何更好地发现、保存和推荐 X 文章。

网站默认仍是文章。「插件与工具」是额外点击进入的页面。工具记录统一放在 `data/tools.json`，生成目录见 [TOOLS.md](TOOLS.md)。本轮未安装扩展、连接账号或部署服务；选型建议与真实使用效果分开。

## 先试哪些

| 需求 | 先评估 | 理由 |
| --- | --- | --- |
| 发现作者和代表作 | [Tweet Hunter X](https://tweethunter.io/tweethunterx) | 从已发现的好作者延伸，比只堆关键词更有方向；官网仍把收藏搜索写成 Coming Soon。 |
| 重复做专题搜索 | [X Search Pro](https://github.com/neonwatty/x-search-pro) | 保存作者、时间窗和互动阈值；它是网页查询工具，不能直接替代数据采集。 |
| 留素材、找回收藏 | [Bookmark X](https://github.com/LucasDitchun/export-bookmarks-x-twitter) | 本地保存、笔记与标签检索、TXT / Markdown 导出，适合接入现有来源组件。 |
| 写草稿和做个人复盘 | [Typefully](https://typefully.com) | 编辑、预览、排期与分析；已有[官方 MCP](https://support.typefully.com/en/articles/13128440-typefully-mcp-server)，尚未接入。 |

这四项先做使用体验比较即可，不需要同时购入一套工具。dewey 是更省配置的收藏服务候选，使用前核对[套餐与导出范围](https://getdewey.co/pricing/)；BookmarkBrain 更适合学习带引用问答，模型 API 费用另计。

## 从源码与产品中学到的具体方法

1. **作者可以成为发现入口。** Tweet Hunter X 的作者代表作、侧栏搜索启发我们：从一篇好文找到作者，再沿历史长文、引用和讨论继续寻找。作者列表仍需按项目维护，不等同于无条件信任作者。
2. **保存查询，不只保存结果。** X Search Pro 将主题、作者与时间窗组合为可复用查询。先宽搜再收窄，分别看热门与最新；点赞门槛过高容易漏掉低曝光的专业文章。相关源码固定版本已随每张卡片保存。
3. **保存理由也是检索字段。** Bookmark X 的检索对正文、作者、笔记、标签与文件夹给予不同权重；可选本地语义检索失败时退回词法检索。对我们的启发是先补“解决什么问题”和保存理由，再评估是否需要向量库。尚未移植它的代码。
4. **推荐理由需要可回源。** BookmarkBrain 先选相关收藏，再构建引用列表并调用模型；引用绑定到原帖 URL。它提示我们把“检索到什么”与“生成了什么解释”分开，附引用也不自动保证结论准确。
5. **内容完整性比页面看起来完整更重要。** xTap 明确拒收缺少正文 blocks 的 Article stub；X Viral Monitor 在统一的网络响应 hook 上分发数据。浏览器虚拟列表和仅有摘要的返回不能当作全文。
6. **热度指标需要说明口径。** X Viral Monitor 的平均流速为累计浏览量除以发布后时间；其页面排行榜不是全 X 排名。后续若研究增长，应保存分时快照，才有依据计算增量。
7. **写作与复盘值得接起来，但不先造全套后台。** Typefully 的草稿工作流和 Postiz 的独立平台适配层可供参考。当前先把素材发现、原文核验和草稿做好；Postiz 部署优先级低。源码许可证为 AGPL-3.0，不能当成 MIT。

## 对文章发现的真实小样本验证

已有共用来源组件具备查询计划、发现、链接导入、原帖读取和恢复能力。本轮运行其 `doctor`，再沿新的官方文档验证一个具体启发。

[FxEmbed 当前文档](https://docs.fxembed.com/api/introduction/)已经列出搜索和作者长文列表；固定版本源码也有对应实现。旧研究中“仅适合已知链接回源”的描述需要拆成不同能力来看，不能继续作为整个上游项目的能力上限。

| 验证 | 实际结果 | 可得结论 |
| --- | --- | --- |
| [v2 搜索](https://docs.fxembed.com/api/twitter/operations/2search/)：中文运营/涨粉查询，count=5 | HTTP 404 | 本轮托管搜索未跑通。文档与源码存在，不能直接记为已接入渠道。 |
| [作者长文列表](https://docs.fxembed.com/api/twitter/operations/2profilehandlearticles/)：从已有作者 @isnail 出发，count=3 | HTTP 200、code 200，实际返回 12 条 | 作者维度能取得真实长文线索；上游未遵守请求数量，后续须本地截断。 |
| 与正式文章库按 status ID 比较 | 1 条已存在，11 条未收录 | 库外不等于适合收录。不少是公众号、副业与生活主题。 |
| 将 12 条真实 URL 交给组件 `import` | 12 条线索导入成功 | 新发现入口可继续复用已有的去重、回源流程，无需重做整个组件。 |
| 组件 `collect` 读取 1 条已有公开主帖 | 返回正文与来源记录；状态 ok | 原有读帖链路本轮可用；没有下载媒体，也没有把技术读取当成全文审读或线程完整性。 |

这次没有向正式文章数据添加候选。作者线索仅在本地研究队列，未自动递归抓取、未翻页，也没有推进全局时间覆盖游标。下一次找文章可先做小批作者长文补搜，再核对正文是否属于 X 运营主题。

## 为什么没有把所有常见工具都推荐进来

本轮实读 8 个仓库的 README / 许可证，其中 7 个进一步定向读源码；另检查了 xarchive 的元数据和目录，以及 5 个商业产品官方页面。结果挑出 10 项进入工具库。

| 额外候选 | 本轮判断 |
| --- | --- |
| [BlackMagic](https://blackmagic.so/) | 官网明确公告于 2026-07-01 停服；商店条目仍可访问不改变这个结论。排除使用推荐。 |
| [Hypefury](https://hypefury.com/features-pricing) | 当前价格页平台列表未列 X，首页旧段落仍提 X，公开说明不一致。待核实支持范围，本轮不推荐为 X 首选。 |
| [Twillot 的 Twitter Bookmarks Search](https://github.com/twillot-app/twitter-bookmarks-search) | MIT；本轮 API 返回最近推送时间为 2025-03-18。与已选收藏工具重叠，当前兼容性未试，不优先。此判断不等于项目已停止维护。 |
| [xarchive](https://github.com/sytelus/xarchive) | 找到导出思路与仓库目录；读取许可证遇到网络 EOF，审查不完整。暂缓，不能冒充源码深读。 |

应用插件目录还返回了 Metricool 等线索，但没有验证当前 X 支持与套餐，未用目录简介直接充当推荐证据。

## 后续试用的完成条件

- 作者发现：同一主题能否找到至少一条有用、此前未收录的真实原文；记录来源，不以搜索结果数替代质量。
- 收藏工具：用用户主动选出的少量收藏验证搜索、中文长文完整性、导出与导入；不需要一开始处理整个账号。
- 写作工具：用一份自己的素材完成草稿、预览与修改；发布与账号授权单独决定。爆款或增长效果需要之后的真实内容表现，不能由工具功能推出。

本轮源码仅作定向阅读，没有复制实现或执行上游安装脚本。公开页面是原创中文说明与来源链接，原始接口返回、源码快照和失败证据仅保留在被忽略的本地研究目录。
