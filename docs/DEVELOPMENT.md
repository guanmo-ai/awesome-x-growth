# 开发与维护

读者入口见 [项目首页](../README.md)；本文面向本地开发与资料维护。

## 本地预览

需要 Node.js 20+，无需安装第三方运行依赖。

```sh
npm run dev
```

会先构建，再在 [127.0.0.1:4186](http://127.0.0.1:4186/) 预览真实发行目录。`npm start` 也会先构建，支持首次启动。其他端口可用 `PORT=4187 npm run dev`。

```sh
npm test
npm run build
npm run check
npm run check:release
npm run check:repo
```

发行检查核对公开模式、文件白名单、图片完整性与来源字段、静态文章、数据一致性、本地链接、分享图片尺寸与正式地址配置。仓库检查另行检查 Git 已跟踪及未忽略文件，检查文章图片是否齐全，并阻止未引用图片、私有目录和已识别凭据模式。研究目录、缓存和构建产物不纳入 Git；网站仅部署 `dist/`。

设置正式 HTTPS 根地址后构建，可生成绝对分享地址、canonical、sitemap 与 robots。子目录部署须将子目录包含在 `SITE_URL` 中。未设置地址时可本地预览，但平台分享卡片、真实域名与搜索抓取尚未验收。详见 [公开版本说明](RELEASE.md)。

## 本机原图审阅

封面和头像保留在 `assets/articles/`，纳入仓库候选并随默认构建展示。日常使用 `npm run dev` 即可看到图片。`npm run dev:preview` 是可选的独立输出模式，构建到 `.local/preview/`，不会覆盖 `dist/`，该模式拒绝 `SITE_URL`。

## 内容维护

- `data/articles.json` 是唯一文章数据源，`data/synthesis.json` 保存带来源 ID 的归纳。正式文章必须有真实作者、来源、日期、核验范围和转载状态，近一年中文原创 Article 才进入前台；不收普通帖或泛平台涨粉内容。
- 原文开头按顺序提取约100字，在完整段句结束并保留格式。AI 总结只提炼已读材料，不补写作者经历；研究正文不公开。
- 数字为有日期的公开接口快照，不是实时数据、后台审计或效果保证。历史策略须结合当前平台规则理解；核验范围和边界保留在源数据中，不把个案归因为普遍增长公式。
- 文章须保留原图路径、尺寸、来源与署名；缺图时构建失败。图片权利归原作者，不能把显示图片或 `localPreview` 记录当成转载授权；如记录 `publicUse`，其说明、证据链接和日期必须完整且真实。工具图标用于识别产品，来源和权利说明见第三方许可。
- `assets/guides.js` 保留备用阅读路线数据，当前首页未启用；移除文章时仍须更新这些引用及专题归纳。隐藏文章后，其独立页和图片退出公开构建。
- 后续研究按项目 AGENTS 和 x-source-research 工作流进行。已知作者列表到底不等于全 X 穷尽，未匹配候选不等于已读或拒收。

工具页保留但未放在首页导航，直接打开 `tools.html` 可查看用途、费用、使用条件、来源和实测边界，不把源码阅读当作安装试用。工具数据只在 `data/tools.json` 维护。
