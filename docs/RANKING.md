# 文章排序

默认「综合推荐」同时考虑原帖收藏与发布日期。保留「收藏最多」和「最新发布」供手动切换；明确带有 `sort=popular` 或 `sort=newest` 的旧链接继续遵循对应排序。

公式：`score = ln(1 + bookmarks) × (0.35 + 0.65 × 2^(-ageDays / 60))`。

收藏越多，得分越高；同样收藏量的文章，较新的优先。对数减小收藏数量的悬殊差距。时间因子由35%的长期底分和65%的新鲜度组成，新鲜度部分每60天减半；总时间因子在60天后是0.675，旧文不会仅因年龄而归零。

例如：7天前100收藏的文章优先于刚发布2收藏的文章；一年前5000收藏的文章仍能排在7天前20收藏的文章之前。新鲜并不单独等于值得优先阅读。

只使用真实收藏及发布日期，不以入库时间、点赞或人工顺序加分。零收藏得零分，未取得收藏数据的条目排在已知数据之后；同分依次按较新的发布日期、较高收藏量及稳定ID排序。日期按日历日计算，不随浏览时刻在同一天内跳动。搜索、主题、时间与收藏门槛先筛选，卡片前后切换与列表使用同一排序。

参数是本站首版选择，并未通过读者效果实验确认为最优值。收藏是采集快照，也受曝光、作者受众和传播背景影响；排序只能帮助发现，内容是否值得收录仍靠来源与原文核验。

方法参考 [Elastic 官方字段变换与时间衰减文档](https://www.elastic.co/docs/reference/query-languages/query-dsl/query-dsl-function-score-query)，公式是面向本库的独立组合，参数并非官方推荐。原始比较及采集证据保存在不公开的研究目录。
