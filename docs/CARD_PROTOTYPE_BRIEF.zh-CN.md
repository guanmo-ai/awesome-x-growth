# 中文卡片资料库：Open Design 设计简报

状态：2026-10-10 已通过 Open Design + Local Codex 完成独立原型及真实浏览器验证；当前为本地候选，视觉方案待用户接受。恢复入口与截图保存在被忽略的 `.research/open-design-card-prototype/HANDOFF.md`。

## 本轮目标

为 Awesome X Growth 制作全中文、可点击的 X / 推特增长资料库原型。先打磨网站样式与交互，正式文章随后接入。最终视觉是否合格由用户验收。

保留现有文章与专题数据。本轮使用独立 Open Design 项目，仅放少量明确标记的中文演示内容；不采集新文章，不把演示数据写入正式资料源。

## 视觉方向

品质目标参考 OpenAI、Claude 等产品的克制、层级与细节，不复制品牌。以精细的中文排版、清晰的卡片轮廓和有节奏的留白建立辨识度。

- 全中文品牌展示可用「增长资料库」，副标题为「关于 X 创作、增长与变现的实践笔记」。维护者署名「观默」。
- 简洁的水平导航，主要入口为「资料库」和「我的收藏」。不要侧栏、装饰曲线、营销横幅、大面积装饰图或虚构统计。
- 浅色中性背景、近黑正文、柔和边框，最多一种克制的强调色。不要把简约退化为只有文字目录。
- 桌面使用有明确边界的文章卡片网格；手机为单列。卡片包含主题、中文标题、短摘要、阅读提示和收藏按钮。信息密度舒适，长短标题都不能破坏层级。
- 头部紧凑，首屏直接看见有用的文章卡片。卡片无需为每篇强加配图；不要用大图、渐变和重复装饰填充版面。
- 细致处理悬停、键盘焦点、选中、已收藏、空态和窄屏；尊重减少动画偏好。

## 必须可操作的交互

1. 搜索中文标题、摘要和标签；显示结果数量，支持清空。
2. 主题筛选：「全部」「账号定位」「内容创作」「互动增长」「数据复盘」「商业变现」。搜索和筛选可组合。
3. 排序：「精选推荐」「收藏最多（演示）」「最新收录」。排序真实改变卡片顺序。
4. 收藏与取消收藏，按钮有明确反馈。收藏保存在当前浏览器；刷新仍保留。无法存储时应提示并保持本次会话可用。
5. 「仅看已收藏」筛选；「我的收藏」中支持「最近收藏」和「最早收藏」。根据个人收藏时间排序，不能用文章收录时间或演示收藏量代替。
6. 卡片可以打开中文阅读详情；返回后保留搜索、主题及排序状态。收藏按钮不能误触发阅读。
7. 无匹配结果、未收藏任何文章均有完整中文空态与恢复操作。
8. 无真实全站统计。凡展示收藏量及按其排序，始终就近标注「演示」，不称真实热度。个人收藏与演示全站收藏量在数据上分开。

## 技术与交付边界

- 优先原生 HTML、CSS、ES modules，避免不必要依赖。免费、本地、可逆。
- 不改动正式的文章和专题数据，不提交、推送、建 PR、部署或联系作者。
- 本轮用户已明确选择 Local Codex，使用本机已登录的 Codex 额度；该模式贯穿 Brief、项目创建、生成与交付。
- 使用一次可追踪的 Open Design Brief 工作流与一次稳定的生成请求；实际生成后跟进到结束，并打开该次运行返回的真实预览。

## 验收方式

实际浏览桌面与手机，不以代码检查代替视觉审看。至少检查 1440 像素桌面、390 像素手机及 320 像素窄屏；长标题、筛选、排序和详情不能溢出。

逐项操作搜索、主题组合、演示收藏量排序、最新收录排序、收藏后刷新、取消收藏、个人收藏时间排序、空态及详情返回。记录真实执行的结果，并交付桌面与手机截图和可打开的预览。

尚未生成时不能声称这些交互已验证，也不能把现有旧站预览作为本轮成果。
