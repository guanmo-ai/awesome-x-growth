# 当前数据约定

2026-10-19。机器约束以 scripts/validate.mjs、scripts/validate-tools.mjs 和测试为准。

`data/articles.json` 是文章唯一源。每条有稳定 id、原标题、作者及主页、真实来源、发布日期、核验日期、主题、阅读范围、转载状态、证据和适用边界。内容覆盖自媒体涨粉、运营与变现，以 X 为重点，保留含实质 X 经验的跨平台比较与通用经营方法；当前暂缓其他平台专项文章。相关性依据正文主线与具体经营方法，不能依赖标题关键词或 AI 总结包装；详见 [内容政策](../CONTENT_POLICY.md#收录范围)。正式资料只接受近一年明确日期；前台进一步要求中文、Article、showcase=true。

`excerpt.kind=opening` 表示作者正文开头，保留来源顺序与格式，有限摘录在完整段句结束。`aiSummary` 至少三项并绑定来源；仅总结已读论述。备用阅读路线保存在 assets/guides.js，当前首页未启用，引用仍须指向真实展示文章。

每篇展示文章必须有原文封面与作者头像，默认构建保留图片，缺少文件必须报错。图片逐条记录路径、类型、尺寸、作者和来源；首页卡片、弹窗与独立阅读页保留原图，不得用 AI 文字提要替代。localPreview 仅保留历史审阅记录，公开投影移除该字段，不以此控制图片显示。如填写 publicUse，必须包含非空 license、无凭据 HTTPS evidenceUrl 与有效日历日期 checkedAt；空对象和不完整记录会被拒绝。显示图片不等于取得转载授权，代码许可证不覆盖第三方图片。

文章默认按综合推荐排序，同时考虑原帖收藏和发布日期，保留收藏最多与最新发布。零收藏与未采集分开处理；公式、参数和适用边界见 [文章排序](RANKING.md)。

policyReview 保存与实际文章内容相关的当前规则核对，不凭 AI/Skill 等关键词判断自动化。真实性、自动操作和平台奖励分别处理；商单收入不自动关联 X 平台奖励规则。

socialSnapshot 必须保留来源、采集时间与提供方，未知值不填零。readingRange.text、images、linkedMaterials 均为必填非空字符串，分开说明文字、配图与外链，不能把取得正文升级为完整线程或数据审计。

构建只把当前展示文章的必要字段投影到 dist/data/articles.json；旧导读、研究笔记与未展示条目不进入前端 JSON。原文、候选和核验原始材料保存在不公开的研究目录。

工具记录用途、费用、访问条件、出处、许可证、固定源码版本和实际核验层级；官方节选与 AI 总结分开。数据缺失、重复、越界路径或不实结构由校验拒绝。
